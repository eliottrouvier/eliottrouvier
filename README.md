### 🚀 Featured Project

#### 📌 [Stanford CS231n — Deep Learning for Computer Vision](https://github.com/eliottrouvier/stanford-cs231n)
*An experiment logbook and modular testbench implementing core computer vision algorithms from scratch.*

| Module | Core Topics | Highlights |
| :--- | :--- | :--- |
| **01** | Image Classification | kNN, Linear SVM, Softmax, Fashion-MNIST benchmark |
| **02** | Regularization | Ridge ($L_2$), Lasso ($L_1$), ElasticNet, Inverted Dropout |
| **03** | Optimization | Batch GD vs Mini-Batch SGD vs Pure SGD dynamics |
| **04** | Momentum | Classical Momentum vs Nesterov Accelerated Gradient (NAG) |
| **05** | Loss Landscapes | Saddle points, local minima traps, Rosenbrock ravine |
| **06** | Adam Optimizer | RMSProp + Momentum blend, bias correction dynamics |
| **07** | Neural Nets & Activations | 20-line NumPy 2-layer net, spiral decision boundaries, vanishing gradients |
